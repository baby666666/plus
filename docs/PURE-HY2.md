# 纯 Hysteria 2 手机接入

在「网络设置 → VPN客户端 → WireGuard」的 WG 隧道列表添加或编辑设备，连接方式选「纯 Hysteria 2（UDP）」。纯 HY2 只提供「让这台设备连接路由器上网」。大陆手机主动连接境外爱快的一个公网 UDP 端口，网页、下载和 DNS 通过 HY2/QUIC 转发。扫码配置可直接使用，手机无需公网地址或入站端口映射。

## 设置与手机导入

1. 为每台设备选独立的服务接口和端口。新隧道默认使用原生 WG，选中纯 HY2 后，公网入口默认取所选 WAN 的公网 IPv4，UDP 端口沿用该接口的端口。境外爱快在上级 NAT 后时，手动填写可从外网访问的 IPv4，并将该 UDP 端口映射到爱快。
2. 在爱快和上级防火墙放行该 UDP 数据端口。这个模式不使用 Realm、协调 TCP 或 STUN。首次启用需让爱快安装并校验 sing-box 1.14.4 核心，优先将核心放在可执行且空间足够的本地 ext 卷上。请在首次安装时保持 WAN 可用。
3. 保存后，重新打开这台设备，按手机上的客户端选择下面的导入方式。每台手机使用自己的凭据。
4. 接收端也是 NativeRouting 时，可以从这个页面「复制到路由器」，在对端 WG 隧道页面粘贴并确认导入。在接收端的分流规则中将要经境外上网的来源指向导入接口。

| 手机客户端 | 在爱快和手机上的操作 |
| --- | --- |
| sing-box | 点「复制 sing-box 配置」。在手机 sing-box 新建本地配置，打开内容编辑器，粘贴完整 JSON，保存后启用。也可扫码或下载 JSON。配置含 VPN 接管和 DNS 规则，默认通过 HY2 使用 1.1.1.1 解析 IPv4 域名。 |
| 支持 HY2 分享链接和证书指纹校验的客户端 | 点「复制 HY2 链接」，在客户端从剪贴板导入节点。链接含设备凭据、UDP 入口和服务器证书指纹。VPN 接管、DNS 和分流由该客户端设置。请确认客户端支持 `pinSHA256`，以便验证爱快的自签证书。[Hysteria 2 链接规范](https://v2.hysteria.network/zh/docs/developers/URI-Scheme/) |

手机浏览器拦截自动复制时，页面会显示所选格式的完整文本。点「全选配置」，再用手机系统菜单复制即可。两种格式均含本设备的登录凭据。

## 核心存储与内存

固件校验固定版本的安装包和核心。磁盘空间充足时，多个设备共用磁盘上一份 87.8 MiB 的核心。可执行的本地 ext 卷放不下完整核心时，固件可在该卷保存 28.2 MiB 的压缩镜像，按需从磁盘读取程序。日志分区额外保留至少 20 MiB。若日志分区已有官方安装包，另有约 49 MiB 可用空间即可容纳镜像和这部分预留空间，已有的安装包可用于恢复。首次生成压缩镜像需要当时有至少 64 MiB 系统可用内存。重启后复用已校验的镜像，无需再次压缩。

在已保存的纯 HY2 设备中展开「连接设置」即可查看压缩磁盘或内存盘提示。没有合适磁盘且运行内存足够时，固件将核心解到内存盘，全部设备共用这 87.8 MiB。每台已启用设备还需要工作内存，流量也会占用网络缓冲区。

## 升级时沿用已有配置

RC16 的单向纯 HY2 保留接入端口和认证信息，已导入的客户端可继续使用。旧 HY2 承载 WG 设备须重新选择方式，详见[旧设备处理](WG-DEVICES.md)。

| RC15 原有纯 HY2 用途 | 升级后的行为 |
| --- | --- |
| 让这台设备连接路由器上网 | 沿用原 UDP 端口及接入凭据。 |
| 双向使用 | 保留设备经爱快出网的方向，取消爱快反向借线。原有正向凭据继续有效。请在手机上重新扫码，替换仍会尝试协调和打洞的旧双向 JSON。 |
| 让路由器借用这台设备的网络 | 停止借线，保留原记录。需要手机经爱快出网时，在中心端明确改成单向接入，保存后重新扫码。旧的借线导入包须按需要从中心重新导出。 |

新版本只接受单向的纯 HY2 导入包。需要境外爱快借大陆手机或路由器的出口，仍可在此页选择「原生 WireGuard」并设置设备用途。需要访问两端已声明的局域网，请选路由器组网。纯 HY2 的互联网出口拒绝管理后台和私网目标。真实跨境速度及移动端锁屏、切网表现取决于实际线路和设备。
