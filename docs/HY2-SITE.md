# 在两台 NativeRouting 爱快之间复制设备配置

两台路由器均使用支持所选连接方式的 NativeRouting 固件。升级后刷新已打开的管理页面。下文将生成配置的一台称为「中心」，粘贴配置的一台称为「分支」。分支主动连接中心的公网 UDP 入口，可以位于 NAT 后面。当前导入配置使用 IPv4。

## 选择设备用途

| 中心端选择的设备用途 | 哪一端能选对方上网 | 连接方式 |
| --- | --- | --- |
| 让这台设备连接路由器上网 | 分支可将指定设备的流量送到中心，从中心 WAN 出网。 | 原生 WireGuard、纯 Hysteria 2 |
| 让路由器借用这台设备的网络 | 中心可将指定设备的流量送到分支，从分支 WAN 出网。 | 原生 WireGuard |
| 双向使用 | 两端都可以选对方上网，各自决定哪些设备走隧道。 | 原生 WireGuard |

仅选择上网用途不会自动公布双方 LAN。中心借用分支宽带时，设备用途仅允许新流量转到分支 WAN，分支管理页及 LAN 仍有单独的访问限制。需要双方 NAS、摄像头等直接互访时请在原生 WG 中填写两端互访网段。

## 复制、导入和分流

1. 中心端打开「网络设置 → VPN客户端 → WireGuard」。为分支添加对端，分配独立密钥和隧道 IPv4 地址，选择连接方式与设备用途。Hysteria 2、借线或双向用途需要独立 WG 接口。需要中心持续借线时可将心跳设为 25 秒。心跳为 0 时，NAT 映射可能在空闲后失效。
2. 核对中心对分支可达的公网地址、UDP 端口，以及上级网关的端口映射。保存对端后，前三种用途点「复制到路由器」，已填写两侧互访网段的原生 WG 使用「生成iKuai组网配置」。配置包含该设备的私钥。若手机和路由器需要同时在线，请给它们分别建立对端，避免同一 WG 身份在两台设备之间切换。手机可继续使用 WG App 的标准配置或 sing-box 的扫码入口。
3. 在分支 WG「隧道列表」点「粘贴导入配置」。粘贴后预览连接方式、入口及本机可以使用的方向，确认再导入。固件会创建专用接口和对端，记下分支实际分配的 `wgN`。原生 WG 直接连接公网 WG 端点。纯 HY2 使用本地安装镜像预置或原地升级保留的核心，缺少有效缓存时首次启用会下载固定版本的 sing-box。
4. 在**借用对方出口的一端**添加分流规则，来源选本地设备或网段，出口选对应的 `wgN`。例如只想让分支 NAS 经中心上网，就在分支添加以 NAS 地址为来源的规则。双向模式可在两边分别指定来源。用新建连接核对出口，规则顺序及断线策略详见[分流顺序](ROUTING-ORDER.md)。

## 两边 LAN 互访的示例

中心 LAN 可用 `192.168.61.0/24`，分支 LAN 可用 `192.168.62.0/24`，中心隧道地址可用 `10.163.12.1/24`，分支对端可分配 `10.163.12.2/32`。请换成自己的网段，两边 LAN 不能重叠，隧道地址也要避开已有路由。中心选原生 WG，填写本端和对端的互访网段，再生成 iKuai 组网配置。分支粘贴生成的 iKuai 组网配置后，核对已填入的本端和对端网段，并保存对端。各 LAN 主机以本端爱快作网关。如果网关在其他设备上，需要为对端 LAN 添加经本端爱快的路由。已有 HY2 承载 WG 的站点在升级后停用，需要两侧改用原生 WG，重新生成并导入组网配置。

同一份配置重复导入会提示已经导入。中心更换用途、密钥、网段或公网入口后，可在分支移除旧导入并粘贴新配置，再把需要使用它的分流规则指向实际分配的接口。被现有分流规则引用的旧接口名会为自动导入保留，已停用规则和多出口列表中的引用也计入。如果页面提示配置已保存但启用失败，请先解决端口或线路故障，再从列表启用该设备。可以在列表中启用、停用或删除导入的设备。列表中的启用、停用和删除会核对选中设备的身份。如果另一个窗口已经替换了其中一台，请返回列表刷新后重新选择。自行调用旧接口的脚本若仅传记录编号，操作会作用于该编号当前对应的设备。整机配置备份包含凭据。更换硬盘后，分支可通过手动启用 HY2 设备来补装所需核心。
