# NativeRouting 3.0

3.0 提供原生 WG 和纯 HY2 两种设备连接方式，文件名与摘要以根目录 `release.json` 为准。

- 纯 HY2 认证后可访问路由器局域网、管理页面并使用原生分流；管理页面仍需独立登录。
- 原生 WG 支持三种上网用途和指定网段互访；两种连接方式都支持复制配置到兼容路由器。
- 手机可复制完整配置、分享链接或扫码；操作按钮使用原生尺寸并自动换行。
- 全新安装镜像预置固定 HY2 核心，支持 BIOS/UEFI；默认 eth0 为 WAN1/DHCP，WAN Web 开启。
- BIN 升级保留现有配置和有效核心缓存；无缓存时首次启用 HY2 自动下载安装固定核心。

新构建使用独立签名密钥及匹配内核。宿主测试、启动与升级验证方法见 [TESTING.md](TESTING.md)。电脑浏览器的手机视口检查不代替真实 iOS/Android 验收，功能测试不代表跨境吞吐或移动网络持续性测试。
