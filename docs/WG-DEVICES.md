# WG 隧道的连接方式与设备用途

在「网络设置 → VPN客户端 → WireGuard」添加或编辑隧道。新建默认使用原生 WireGuard。每台手机或路由器分别建立一个对端，以便单独停用、更换密钥或查看状态。

| 设备用途 | 原生 WireGuard | 纯 Hysteria 2 |
| --- | --- | --- |
| 让这台设备连接路由器上网 | 设备主动连接爱快，使用爱快的出口 | 设备经 HY2/QUIC 连接爱快，使用爱快的出口 |
| 让路由器借用这台设备的网络 | 爱快可以将分流规则指向设备，由设备提供出口 | — |
| 双向使用 | 设备经爱快出网，同时可为爱快提供出口 | — |

多 WAN 路由器自动填写公网 IPv4 时，会核对默认出口和两次路由查询。如果默认出口与查询结果冲突，请在 WG 服务接口上指定 WAN，或手动填写手机可以访问的公网地址。

### 在手机上复制原生 WG 配置

设备若在 NAT 后，可按实际需要设置心跳。保存隧道后，打开对应的原生 WireGuard 设备，按手机使用的客户端选择。

| 手机客户端 | 操作 |
| --- | --- |
| WireGuard | 点「复制 WG 配置」，可一次复制含 `[Interface]` 和 `[Peer]` 的完整配置。可以把文本保存为 `.conf`，在 WireGuard 中从文件导入。手边有第二块屏幕时，也可以用原有二维码扫码导入。[WireGuard Android 导入选项](https://github.com/WireGuard/wireguard-android/blob/master/ui/src/main/res/values/strings.xml) · [iOS 导入选项](https://github.com/WireGuard/wireguard-apple/blob/master/Sources/WireGuardApp/Base.lproj/Localizable.strings) |
| sing-box | 已保存并启用的手机上网、借线或双向设备可点「复制 sing-box 配置」。在手机 sing-box 新建本地配置，把完整 JSON 粘贴到内容编辑器并保存。借线和双向设备应独占 WG 接口。[原生 WG 手机借线](SINGBOX-EXPORT.md) |

浏览器拦截自动复制时，点「全选配置」，再用手机系统菜单复制。两种格式中均包含该设备的私钥。

纯 HY2 支持复制完整 sing-box 配置和 HY2 分享链接。每台设备独占公网 UDP 端口，默认取所选 WAN 的公网地址以及接口设定的端口。手机和另一台爱快的导入步骤见[纯 HY2 接入](PURE-HY2.md)和[复制到另一台路由器](HY2-SITE.md)。

新增 WG 接口时，只有保存配置和应用运行设置均完成，页面才会确认成功。若提示“已撤销本次新增”，修正提示中的问题后可以重试。若提示“已保存”或浏览器没有收到回执，请回到接口列表核对原记录；已存在的接口应从列表打开检查，无需再建一次。接口没有启用的对端时，即使配置正确，也不会显示已连接。

## 原来使用 HY2 承载 WG 的设备

升级后两端的旧设备均停用。中心端可编辑旧设备，明确改选可用的方式，核对用途和公网入口后保存并启用。重新为手机扫码，或复制新的路由器配置。在另一台爱快删除已停用的旧导入，再粘贴新配置并核对分流出口。原生 WG 使用时对端必须能直接通过 UDP 到达 WG 端口。
